# Atualização editorial semanal

Destino: https://quadrantes-journal.vercel.app/ — GitHub Faelcripto/quadrantes-journal, branch main, publicação automática Vercel. O antigo projeto Sites não é o destino atual.

1. Leia a versão atual de main, `lib/macro-types.ts`, `lib/site-content.ts`, `lib/cot.ts` e os JSON existentes. Preserve as demais alterações do usuário.
2. Pesquise fatos dos últimos sete dias e eventos USD/EUR dos próximos 14 dias em fontes oficiais: BLS, BEA, Federal Reserve, DOL, ECB, Eurostat. Guarde links das publicações e datas reais. Não confunda data de divulgação e período de referência.
3. Atualize `data/macro-weekly.json`. A data `updatedAt` pertence ao resumo; `calendarUpdatedAt` pertence à verificação da agenda. Não atualize a data de conteúdo que não foi verificado. Preserve registros anteriores quando a fonte falhar.
4. Cada evento tem impacto editorial explícito (`Alto`, `Moderado`, `Baixo` ou `Não classificado`), moeda, ativos, explicação simples, cenários condicionais e fonte. A sinalização de fogo usa somente eventos de impacto `Alto` na data atual em America/Sao_Paulo, inclusive já divulgados. Não invente um evento para ativar o sinal.
5. Converta o horário da fonte para UTC com a zona IANA de origem e horário de verão da data do evento. `date` corresponde ao dia em Brasília; `at` é ISO UTC ou null se não confirmado. A interface converte UTC para Brasília.
6. `previous`, `forecast` e `actual` só recebem valores confirmados, cada um com seu `previousSource`, `forecastSource` ou `actualSource`. Na ausência, deixe texto vazio e fonte vazia. Não preencha percentuais de probabilidade. Favorável/desfavorável são cenários, nunca sinais ou certeza de valorização.
7. COT: use a API pública CFTC TFF Futures Only `gpe5-46if`, códigos `098662` e `099741`, campos/validação definidos em `lib/cot.ts`. Preserve categorias gestores e alavancados, datas de referência e publicação. Contratos não são dinheiro entrando ou saindo. Se atrasado ou indisponível, preserve snapshot e datas anteriores.
8. O painel administrativo pode sobrescrever o JSON por `site_content` key `macro` no Supabase. Verifique a fonte ativa antes de anunciar uma atualização visível. Preserve edições manuais; use controle de revisão para atualização editorial autorizada. Não apague overrides nem altere autenticação, RLS ou operações pessoais. Sem acesso à fonte ativa, relate o impedimento.
9. Execute `node tests/site-content.cjs`, `node tests/economic-calendar.cjs`, `npm run typecheck` e `npm run build`. Publique apenas os arquivos editoriais necessários sobre o HEAD atual, com lease/expected_sha. Espere o status Vercel `success` do commit para confirmar a publicação. Informe datas, fontes indisponíveis e limitações. A agenda não é um feed de resultados em tempo real.
